## Networks

Running more than one server? [PumboProx](https://github.com/PumboMC/PumboProx) is the proxy for Pumpkin networks, with plugins in WebAssembly. PumboPerms runs on it too: ranks live in one place for the whole network and can differ from server to server.

PumboProx and the other Pumbo plugins are still MVPs. We will bring every plugin to production state.
